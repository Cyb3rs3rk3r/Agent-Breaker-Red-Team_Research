# Agent Breaker Red Team Research

This repository documents my hands-on AI red teaming research while working through Lakera's Agent Breaker challenges.

The goal of this project is not to publish challenge solutions or copy/paste payloads. Instead, I'm documenting my testing methodology, techniques tested, findings, security implications, and potential mitigations.

## Current Progress

- **Agents:** 10
- **Levels per Agent:** 5
- **Total Challenges:** 50
- **Levels Completed:** 17/50


## Research Methodology

Each write-up focuses on:

- Objective
- Attack
- Attack Objective
- Attack Surface
- Target Control
- Techniques Tested
- Findings
- Security Assessment
- Impact
- Mitigation

Rather than documenting every individual prompt attempt, I group testing by technique. This keeps the focus on the attack hypothesis, what the agent's response revealed about its controls, and how that information influenced the next technique.

## Research Series
This series will focus on each agent at each level

Additional levels will be added as the series progresses.

## Scope

All testing documented in this repository was performed within Lakera's Agent Breaker challenge environment.

Successful payloads may be intentionally withheld or generalized. The focus of this repository is adversarial methodology, security analysis, and mitigation rather than providing step-by-step challenge solutions.
